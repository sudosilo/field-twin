[ FIELD TWIN ]

Companion screen installer

Plug the Waveshare board into this computer with a USB C cable, then press the button and pick the port named USB JTAG serial debug unit.

This browser cannot talk to the board. Open this page in Chrome or Edge on a laptop or desktop. This page needs a secure connection to reach the board.

If the board does not show up or the install stops, unplug it, hold the BOOT button, plug it back in, let go of BOOT, and press install again.

When it finishes, the screen shows FT Companion and the board appears in Bluetooth as FT Companion.
